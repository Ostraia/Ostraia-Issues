# Ostraia-Issues

**Publiczne repozytorium do zgłaszania błędów, sugestii i opinii dotyczących projektu Ostraia.**

> 🔒 Uwaga: Kod źródłowy projektu jest prywatny i nie jest dostępny w tym repozytorium.

## 📌 Do czego służy to repozytorium?

To miejsce, w którym możesz:
- zgłosić błąd lub problem, który napotkałeś podczas korzystania z Ostraia,
- zasugerować nową funkcjonalność lub ulepszenie,
- podzielić się opinią lub zadać pytanie dotyczące projektu.

## ✅ Jak zgłosić problem lub sugestię?

1. Przejdź do zakładki **Issues**.
2. Kliknij przycisk **New issue**.
3. Wybierz odpowiedni szablon (jeśli dostępny) lub opisz swój temat w nowym zgłoszeniu.
4. Dodaj jak najwięcej szczegółów — pomoże nam to szybciej rozwiązać problem.

## 📣 Zasady

- Zachowuj kulturę wypowiedzi.
- Sprawdzaj, czy podobne zgłoszenie już istnieje — możesz dodać swój komentarz lub 👍.
- To repozytorium nie zawiera kodu — służy wyłącznie do komunikacji.
